# 簿記3級 仕訳フラッシュカード

簿記3級の仕訳をフラッシュカード形式で学べる、単一HTMLファイルのWebアプリ。

## 何をする物か
- 仕訳問題をカード形式で出題・復習する学習用フラッシュカード
- 現金過不足を含む総合版

## 使い方
- `index.html` をブラウザで開くだけで使える
- GitHub Pagesにこのフォルダを置けば、URLで公開できる想定（まだ公開はしていない）

## 技術・データの扱い
- HTML 1ファイルで完結（約26KB）。外部の画像・ライブラリ・APIは一切読み込まない
- サーバー処理なし
- 「苦手チェック」は開いた人自身のブラウザの localStorage にだけ保存され、他の人に見えたり共有されたりしない
- スコアはメモリ上のみで、ページを再読み込みするとリセットされる

## 状態・確認済み事項
